## Project Overview

KK Ajax Monitor is a Chrome extension built with React and TypeScript that intercepts and modifies AJAX requests. The extension allows users to create rules that match URL patterns and override request/response data for testing and development purposes.

## Development Commands

### Build and Development
- `npm run build` - Production build using webpack
- `npm run watch` - Development build with file watching
- `npm run clean` - Clean the dist directory
- `npm run test` - Run Jest tests
- `npm run style` - Format code with Prettier

### Browser Extension Development
- Load the `dist` directory in Chrome's extension developer mode
- Use `npm run watch` for live development with automatic rebuilds

## Core Architecture

### Extension Components
- **Background Script** (`src/background.js`) - Service worker that handles extension lifecycle, manages content script injection, and facilitates communication between components
- **Content Script** (`src/content_script.js`) - Injected into web pages to create floating panels and control buttons
- **Page Script** (`src/main.jsx`) - Core AJAX interception logic that overrides `XMLHttpRequest` and `fetch` APIs
- **Main Panel** (`src/mainpanel.tsx`) - Primary UI built with React and Ant Design for managing interception rules
- **Popup** (`src/popup.tsx`) - Extension popup interface

### Key Features
- **AJAX Interception**: Intercepts both XMLHttpRequest and fetch requests using custom wrapper functions
- **Rule-based Matching**: Supports normal string matching and regex patterns for URL filtering
- **Response Override**: Allows overriding response data with static JSON or dynamic JavaScript functions
- **Floating Panel**: Optional on-page floating panel showing intercepted requests
- **Import/Export**: JSON-based rule import/export functionality
- **Mock Data Generator**: Automated generation of test data based on table column definitions

### Data Flow
1. Page script (`main.jsx`) intercepts AJAX requests using custom XHR/fetch wrappers
2. Rules are stored in Chrome's local storage and synced across components
3. Background script manages communication between content scripts and the main panel
4. Content script provides on-page UI elements (floating panel, control button)
5. Main panel provides comprehensive rule management interface

### Chrome Extension Structure
- **Manifest V3** configuration in `public/manifest.json`
- **Content scripts** run on all URLs to inject interception code
- **Web accessible resources** allow page scripts to access extension files
- **Storage API** used for rule persistence and settings

### Component Architecture
- **React/TypeScript** frontend with Ant Design UI components
- **Monaco Editor** for advanced JavaScript function editing
- **JSON Editor** for response data manipulation
- **Modular component structure** in `src/components/`

### Build System
- **Webpack** configuration split across development and production
- **Babel** for JavaScript/JSX transpilation
- **TypeScript** compilation with ts-loader
- **LESS/CSS** processing for styles
- **Copy plugin** for static asset handling

## File Structure Notes

### Source Files (`src/`)
- `background.js` - Extension background service worker
- `content_script.js` - Injected content script
- `main.jsx` - Core AJAX interception logic
- `mainpanel.tsx` - Primary management interface
- `popup.tsx` - Extension popup
- `components/` - Reusable React components
  - `Editor/` - Monaco code editor wrapper
  - `Replacer/` - Rule replacement UI component

### Build Output (`dist/`)
- Generated by webpack, contains compiled extension files
- `js/` directory contains bundled JavaScript files
- Static assets copied from `public/` directory

### Configuration
- `webpack/` - Webpack configuration files (common, dev, prod)
- `public/` - Static assets and manifest.json
- Package.json contains all build scripts and dependencies
